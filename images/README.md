# Memories Photo Directory

Place your personal photos here to show up in the Memories Gallery on the website.

### Recommended File Names
By default, the website looks for:
- `memory-1.jpg` (or `.png` / `.webp`)
- `memory-2.jpg`
- `memory-3.jpg`
- `memory-4.jpg`
- `memory-5.jpg`
- `memory-6.jpg`

### How to Customize
You can change the photo filenames, dates, and captions anytime in `js/config.js` under the `memories` list.

### Fallback Behavior
If an image is not yet added, the gallery automatically displays an elegant romantic illustration card with your caption so the layout never breaks!
